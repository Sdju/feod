# Структура проекта

В этом разделе подробно описаны все сущности, из которых состоит проект по методологии FEOD.

## Сущности проекта

- [App](/structure/app) — сущность приложения для запуска и настройки
- [Pages](/structure/pages) — страницы приложения
- [Modules](/structure/modules) — модули бизнес-логики
- [Common](/structure/common) — общие переиспользуемые сущности
- [Global](/structure/global) — глобальные сущности (опционально)
