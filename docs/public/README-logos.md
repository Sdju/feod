# FEOD Логотипы

Набор SVG логотипов для FEOD (Fractal Entity Oriented Design).

## Доступные версии

### 1. `feod-logo.svg` (Основной)
Полная версия логотипа с детализацией:
- Размер: 200x200px
- Градиент от синего к циану
- Показывает фрактальную структуру с вложенными модулями
- **Использование**: Главный логотип в шапке сайта, большие баннеры

### 2. `feod-logo-simple.svg` (Упрощённый)
Упрощённая версия для лучшей читаемости:
- Размер: 200x200px
- Меньше деталей, более чистый дизайн
- **Использование**: Средние размеры, когда нужна лучшая читаемость

### 3. `feod-logo-icon.svg` (Иконка)
Компактная версия для маленьких размеров:
- Размер: 64x64px
- Оптимизирован для favicon и маленьких иконок
- **Использование**: Favicon, иконки в навигации, социальные сети

### 4. `feod-logo-monochrome.svg` (Монохромный)
Версия без цвета для универсального использования:
- Размер: 200x200px
- Градации серого
- **Использование**: Печать, тёмные/светлые темы, когда цвет недоступен

## Использование в HTML

```html
<!-- Основной логотип -->
<img src="/feod-logo.svg" alt="FEOD Logo" width="200" height="200">

<!-- Иконка в навигации -->
<img src="/feod-logo-icon.svg" alt="FEOD" width="32" height="32">

<!-- Favicon -->
<link rel="icon" type="image/svg+xml" href="/feod-logo-icon.svg">
```

## Использование в CSS

```css
.logo {
  background-image: url('/feod-logo.svg');
  background-size: contain;
  background-repeat: no-repeat;
  width: 200px;
  height: 200px;
}
```

## Использование в VitePress

В `config.mts`:

```typescript
export default defineConfig({
  title: "Open FEOD",
  logo: '/feod-logo.svg',
  // ...
})
```

## Цветовая схема

- **Основной градиент**: `#1e3a8a` → `#3b82f6` → `#06b6d4`
- **Акцент**: `#60a5fa` → `#34d399`
- **Монохром**: `#1a1a1a` → `#4a5568`

## Концепция дизайна

Логотип отражает ключевые концепции FEOD:

1. **Фрактальность** - вложенные квадраты показывают самоподобную структуру
2. **Модульность** - угловые модули представляют независимые блоки кода
3. **Иерархия** - три уровня квадратов соответствуют уровням архитектуры
4. **Структурированность** - геометрические формы показывают организованность

## Лицензия

Логотипы доступны для использования в проектах, связанных с FEOD.
