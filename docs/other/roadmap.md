# Roadmap

Данная страница показывает путь развития проекта FEOD и его экосистемы. Пункты могут быть перемещены на другие этапы или удалены. Достижение всех пунктов не является обязательным для перехода на следующий этап. За исключением пунктов, отмеченных ⚠️.

Легенда:
- ⚠️ - обязательно для перехода на следующий этап
- 🟩 - частично достигнуто
- ✅ - достигнуто
- ⬜ - не достигнуто
- ⌛ - в планах / отложено на следующий этап
- ❓ - под вопросом, может быть вообще отменено

## SMLab development (2024-2025)

Изначально проект FEOD разрабатывался для нужд компании SMLab. Как централизованное решение для всех Frontend проектов компании. Оно прошло опробирование в нескольких проектах и показало себя хорошо.

По результатам работ кроме закрытой презентации и документации была выпущена статья, где FEOD увидел свет в публичном доступе.

- Опробирование идей внутри компании
- Закрытая презентация и документация
- Закрытый генератор проектов на FEOD
- Публикация статьи на Habr открытом доступе в корпоративном блоге
  - [От хаоса к структуре: как FEOD помогает упорядочить архитектуру фронтенд-приложений](https://habr.com/ru/companies/sportmaster_lab/articles/972410/)
