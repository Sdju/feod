# План подготовки к публичному релизу FEOD

Рабочий план оставшихся задач до первого публичного релиза FEOD.
Он конкретизирует подготовку к релизу. Долгосрочное развитие проекта описано
в [общем roadmap](docs/other/roadmap.md).
Даты следующих шагов определяются после завершения предыдущих.

Статус обновлён 26 октября 2026 года. Выполненные пункты отмечены `[x]`.
Каждый шаг ниже содержит результат, по которому проверяем его завершение.

- [x] Документация доступна на [feod.dev](https://feod.dev).

- [x] `@o-feod/eslint-structure-plugin@0.1.0` опубликован в npm.
- [x] `@o-feod/oxlint-structure-plugin@0.1.0` опубликован в npm.
